# Found Again — Resort Lost & Found

A public-facing product concept for a modern lost-and-found platform built around resort and casino operations. The landing page presents guest reporting, smart matching, chain of custody, verified pickup, transparent tracked shipping, security, and special-item workflows.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Stack

- Vite
- React + TypeScript
- Plain responsive CSS
- Lucide icons

The hero artwork was generated specifically for this concept and lives at `public/assets/hero-return-journey.png`.
